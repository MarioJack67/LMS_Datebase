

# LMS_Datebase

## Project Overview
A working SQL script that initializes a learning management system, similar to Canvas and other educational tools.
The first half of the script creates the necessary tables, relationships, constraints, and sample records to mimic a management system.
The back half contains verification queries and advanced features like procedures, indexes, and triggers to showcase the scalability of the database
to handle large datasets in the future.

## Technical Highlights
- 11 relational tables
- 20+ foreign key relationships
- Views
- Stored procedures
- Scalar functions
- Triggers
- Performance indexes
- Sample reporting queries

## Challenges
1. Maintaining referential integrity
2. Calculating grades dynamically
3. Optimizing common lookups

## Solutions
1. Foreign key constraints
2. Trigger-based recalculations
3. Nonclustered indexes
